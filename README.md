# 满觉陇 · 桂雨山径

杭州满觉陇一带的 3D 徒步行程地图，可安装为手机 App（PWA）。

- 两条路线：半日 3h / 全日 7h，含点位顺序、步行与公交接驳
- 3D 视角 + 手绘风格点位标注，点位聚焦时其余点位自动淡化
- 两种浏览方式：左侧列表 / 底部卡片轮播，都会联动地图上的小人
- 支持「添加到主屏幕」，全屏无地址栏打开，离线可加载外壳

## 目录

| 文件 | 用途 |
| --- | --- |
| `index.html` | 单文件应用（样式、脚本、图标全部内联） |
| `manifest.json` | PWA 清单（名称、图标、启动方式） |
| `sw.js` | Service Worker，只缓存外壳，地图瓦片与照片走网络 |
| `icon-*.png` | 应用图标（含 maskable） |
| `.nojekyll` | 关闭 GitHub Pages 的 Jekyll 处理 |

## 说明

地图底图使用腾讯地图 JS API GL 渲染，需要在腾讯位置服务控制台为该域名配置白名单。
页面运行时不调用检索 / 路线规划接口，路线与点位数据均为静态内置。
